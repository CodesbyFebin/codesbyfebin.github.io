Verifiable AI cookbook

Scaffold for verifiable-AI explanations and examples. The current generic README does not establish private model inference, proof-backed AI outputs, or benchmarked verification. It remains a documentation contribution opportunity.

What to inspect

A first recipe should state exactly what the check proves, which inputs are public, and what remains trusted. Include the verifier procedure and a negative control. Keep an authenticated assertion distinct from a cryptographic proof of computation.
